# Netflix Landing Page

A responsive Netflix-inspired landing page built using **HTML** and **CSS**. This project recreates the look and feel of the Netflix homepage with a modern UI, responsive layout, and an interactive FAQ section.

---

## 🚀 Features

- Fully responsive design (mobile, tablet, desktop)
- Netflix-style hero section
- Navigation bar with logo and sign-in button
- Get Started section with form inputs and buttons
- Feature highlight sections
- Embedded video/trailer section
- Interactive FAQ section using `<details>` and `<summary>`
- Clean and beginner-friendly code structure
- Custom favicon included
- Hover effects and smooth UI styling

---

## 🛠️ Built With

- HTML5
- CSS3
- Google Fonts

## 🎯 Objective

This project was created as part of a frontend development assignment focused on practicing HTML and CSS fundamentals by recreating a Netflix-inspired landing page.

The goal was to combine structure and styling while building a user-friendly and responsive webpage with a functional FAQ section.

---

## 🏆 Outcomes

Through this project, I practiced and improved my understanding of:

- Semantic HTML structure
- Responsive web design principles
- CSS Flexbox and Grid layouts
- Forms, buttons, and media elements
- Styling interactive FAQ sections
- Organizing clean and reusable code
- Using favicons and custom fonts
- Mobile responsiveness with media queries

---

## ✨ FAQ Section

The FAQ section was built using semantic HTML elements:

```html
<details>
  <summary>What is Netflix?</summary>
  <p>Netflix is a streaming service with movies and shows online.</p>
</details>
```

### Features

- Expand/collapse functionality without JavaScript
- Styled to match the Netflix dark theme
- Fully responsive on smaller screens
