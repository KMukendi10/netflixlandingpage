# Netflix Landing Page

A responsive Netflix-inspired landing page built using HTML and CSS. This project recreates the look and feel of the Netflix homepage with a modern UI and responsive layout.

## 🚀 Features

- Fully responsive design (mobile, tablet, desktop)
- Netflix-style hero section
- Navigation bar with logo and sign-in button
- Feature highlight sections
- FAQ accordion section (optional if implemented)
- Clean, modern UI design
- Beginner-friendly frontend structure

## 🛠️ Built With

- HTML5
- CSS3
